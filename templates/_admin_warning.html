Change the admin password before the real election.

The admin password is weak (a common one like "admin123", or shorter than 10 characters). Anyone who guesses it can open this dashboard. Use a long password that only COMELEC knows.

How to change it
  • This laptop: open run-local.ps1 and change the line $env:ADMIN_PASSWORD = "admin123" to your own long password, then restart BotoKo. (Or type $env:ADMIN_PASSWORD = "your-long-password" in the terminal before .\run-local.ps1.)
